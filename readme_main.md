## 📖 Описание

Репозиторий **Gudi00/Gudi00** — это специальный GitHub-репозиторий, содержимое которого автоматически отображается на странице профиля автора. Здесь хранится `README.md`, выполняющий роль интерактивного резюме: рассказывает о навыках, образовании, проектах и способах связи. Проект помогает рекрутерам и потенциальным работодателям сразу получить полное представление об авторе, не переходя на сторонние ресурсы.

## 💡 Как появилась идея

GitHub поддерживает специальный «профильный» репозиторий: если его имя совпадает с именем пользователя, `README.md` внутри него становится лицом аккаунта. Это удобная альтернатива традиционному резюме — всегда актуальная, видная всем и легко обновляемая через обычный коммит.

## 🚀 Установка и запуск

Это документационный репозиторий — исполняемого кода нет. Чтобы адаптировать профиль под себя:

```bash
# 1. Создай репозиторий с именем, совпадающим с твоим GitHub-ником
#    (например, github.com/your-username/your-username)

# 2. Клонируй этот репозиторий как отправную точку
git clone https://github.com/Gudi00/Gudi00.git my-profile
cd my-profile

# 3. Отредактируй README.md под себя
# (замени имя, навыки, проекты и контакты)

# 4. Запушь изменения
git add README.md
git commit -m "Update profile README"
git push origin main
```

После пуша GitHub автоматически отобразит `README.md` на странице твоего профиля.

## ⚙️ Как реализован проект

Профиль строится на одном файле `README.md` с GitHub Flavored Markdown:

- **Бейджи** генерируются сервисом [shields.io](https://shields.io) — достаточно подставить нужное название технологии в URL-шаблон.
- **HTML-теги внутри Markdown** (`<br>`) используются там, где нужен принудительный перенос строки.
- **Ссылки-картинки** (`[![badge](url)](link)`) создают кликабельные бейджи-кнопки для контактов.
- Ветка `update-readme` используется для внесения изменений без прямого коммита в `main`, что позволяет просматривать черновик перед публикацией.
